

Repositório criado para estudar e praticar a linguagem Go, reunindo exercícios e pequenos projetos desenvolvidos durante o aprendizado.

🎯 Objetivo

Utilizar este repositório como um ambiente de experimentação para:

Praticar a sintaxe da linguagem Go;
Desenvolver a lógica de programação;
Testar diferentes recursos da linguagem;
Criar pequenos exercícios e projetos;
Registrar a evolução durante os estudos.

📚 Conteúdos

Atualmente, o repositório conta com exercícios voltados à prática dos fundamentos de Go, incluindo estruturas de repetição e desenvolvimento de pequenos programas.

Projetos
Calculadora — exercício desenvolvido para praticar estruturas de repetição e lógica utilizando Go.

Novos exercícios e projetos serão adicionados conforme o avanço nos estudos.

🛠️ Tecnologia
Go (Golang)

🚀 Sobre o repositório

Este é um repositório de estudos e experimentação. O objetivo não é apresentar uma aplicação final, mas registrar a prática e a evolução no aprendizado da linguagem Go.
